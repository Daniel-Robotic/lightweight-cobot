# RobotPowerControl

**RobotPowerControl** — фоновая задача SunriseWorkbench для штатного выключения и быстрой перезагрузки контроллера KUKA Sunrise Cabinet прямо со smartPAD. После запуска задачи на smartPAD появляется панель **System** с двумя пользовательскими кнопками: **REBOOT** и **SHUTDOWN**.

Такой способ особенно полезен при неполадках с аккумулятором контроллера: нажатие физической кнопки питания в этом случае может привести к резкому отключению. Задача позволяет сначала корректно завершить работу контроллера либо быстро перезагрузить его, не переходя к шкафу управления.

!!! warning "Перед выключением или перезагрузкой"
    Остановите движение робота и убедитесь, что операция безопасна для всей роботизированной ячейки. Кнопки управляют питанием **контроллера**, поэтому после подтверждения соединение с роботом и запущенные приложения будут прерваны.

## Исходный код

Java-класс задачи находится в проекте по пути [`src/iiwa_sunrise/src/RobotPowerControl.java`](https://github.com/Daniel-Robotic/lightweight-cobot/blob/dev/src/iiwa_sunrise/src/RobotPowerControl.java). По ссылке его можно открыть или скачать для добавления в Sunrise-проект.

Скрипты выключения и перезагрузки уже находятся на контроллере. Задача вызывает их через `cmd.exe` по путям `D:\\Programme\\reboot.cmd` и `D:\\Programme\\shutdown.cmd`.

## Запуск задачи

`RobotPowerControl` запускается как фоновое приложение (`backgroundTask`). Подробное описание раздела **Приложения** приведено в отдельной [инструкции по приложениям smartHMI](../features/applications.md).

![RobotPowerControl в списке фоновых приложений](../../assets/programms/power_control/apps.png)

На скриншоте видно, что `RobotPowerControl` находится в списке **Фоновые приложения** и отмечен зелёным индикатором.

## Использование кнопок smartPAD

| Кнопка | Действие |
|---|---|
| **REBOOT** | Запускает `reboot.cmd` и перезагружает контроллер. |
| **SHUTDOWN** | Запускает `shutdown.cmd` и корректно выключает контроллер. |

Чтобы открыть пользовательские кнопки, воспользуйтесь боковым меню smartPAD. Подробное описание этого элемента интерфейса приведено в разделе [Функциональные кнопки smartPAD](../features/station.md#smartpad). В панели **System** находятся кнопки **REBOOT** и **SHUTDOWN**.

![Выбор панели System с кнопками управления питанием](../../assets/programms/power_control/choose.png)

Для защиты от случайного нажатия каждая кнопка требует подтверждения:

1. Нажмите **REBOOT** или **SHUTDOWN**. smartHMI покажет предупреждение о критической операции.
2. Повторно нажмите кнопку в окне подтверждения, только если действительно хотите выполнить выбранное действие.
3. После подтверждения соответствующий скрипт запускается. Индикатор кнопки кратковременно становится жёлтым; если скрипт не удалось запустить, он на две секунды загорается красным, после чего возвращается к серому состоянию.

![Подтверждение критической операции](../../assets/programms/power_control/use-btn.png)

На изображении показано окно, которое появляется после первого нажатия. Для запуска операции кнопку необходимо нажать повторно.

Задача передаёт запуск скрипта операционной системе и не ожидает его завершения: контроллер самостоятельно начинает выключение или перезагрузку. Если индикатор стал красным, обратитесь к администратору контроллера для проверки системных скриптов.
